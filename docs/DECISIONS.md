# Решения и открытые вопросы

## Зафиксированные решения

| Область | Решение |
| --- | --- |
| Назначение | Внутреннее приложение одной компании для предварительной сметы ввоза в Казахстан. Клиенты доступа не получают. |
| Backend | Go + Gin, PostgreSQL, GORM для запросов, схема — SQL-миграции golang-migrate. |
| Frontend | React + TypeScript + Vite. |
| Деньги | `shopspring/decimal`, PostgreSQL `NUMERIC`, десятичные строки в JSON; без float-арифметики в расчёте. |
| Округление | По правилам заполнения декларации, математически (5 и больше — вверх). Деньги — до двух знаков: цена товара (гр.42), таможенная стоимость (гр.45, считается от уже округлённой цены), пошлина, антидемпинг и НДС с основой начисления (гр.47), сбор, итоги (гр.12, 22, B — суммы округлённых значений строк). Вес брутто и нетто (гр.35, 38) — до трёх знаков, меньше одного грамма — до шести. Количество — только целое (штуки, пары). Правила — в `backend/internal/service/rounding.go` и `frontend/src/shared/lib/rounding.ts`. Цена единицы (4 знака) и вес одной единицы — вспомогательные значения, не графы декларации. |
| XLSX | Excelize; только явно поддержанные структура и способы хранения изображений. |
| Ставки сметы | Пошлина (ЕТТ) и НДС — только из номенклатуры ТН ВЭД ЕАЭС по коду строки; сервер подставляет их при каждом расчёте и не доверяет ставкам из браузера. Справочники дают наименование и ИТС. |
| Антидемпинг | Меры — из реестра ЕЭК (remedies.eaeunion.org): при первом запуске из файла программы, затем администратор обновляет кнопкой на странице «Номенклатура». Начисляется, если код строки совпал с точным кодом меры и страна происхождения сметы — из списка стран меры; ставка — «для прочих производителей». Совпадение только с товарной позицией — подсказка без начисления; страна не указана — предупреждение; мера временно не применяется — не начисляется. Антидемпинг входит в базу НДС. |
| ТС по СИР | Режим сметы «по СИР»: ТС = вес (нетто или брутто — выбор на смету) × индикатор КГД, USD за 1 кг, × (1 − снижение %), до двух знаков в USD, × курс USD; доставка и доп. расходы — сверху, доставка всегда (цена инвойса, в которую она могла входить, в ТС не участвует). Индикатор — из колонки страны сметы (по умолчанию CN); страна в нескольких колонках профиля — самая узкая; код в нескольких профилях — больший индикатор. «-» и 0 в файле — индикатора нет: строка по инвойсу с предупреждением. ТС, введённая напрямую в тенге, важнее СИР. |
| ИИ | DeepSeek через OpenAI-совместимый API: подбор цен под бюджет, керамика, агент подбора кода. Модель не добавляет кодов и цитат: итог проверяется программой. Ключ хранится только на сервере. |
| Миграции | Применённые миграции не меняются и не удаляются (боевая база хранит номер версии); изменения схемы — только новыми миграциями. |

## Структура кода (2026-10-02)

- **Backend:** `internal/http` → `internal/service/<подпакет>` → `internal/repository`. Подпакеты
  сервиса (`ai`, `auth`, `calculation`, `ceramics`, `decisions`, `directory`, `employees`, `goods`,
  `rates`, `riskindicators`, `tnvedagent`) не зависят друг от друга по кругу; общее — в корне `service`
  (`ValidationError`, десятичные и текстовые помощники).
- **Frontend:** модули `features/*` не импортируют код друг друга, кроме API-клиентов; всё общее
  (HTTP-клиент, разбор Excel, типы смет, формат кода и типы номенклатуры, общие компоненты и стили)
  — в `shared/`. CSS лежит рядом с компонентом, общий стиль модуля — в корне модуля.
- Старых имён («gloves», «gloves-copy»), псевдонимов и редиректов в коде и API нет. Исключение —
  ключи черновиков в браузере (`tradeflow.gloves-copy.*`): по ним читаются несохранённые на сервере
  правки.

## Предварительный расчёт партии

Одна смета — одна декларация. Строки хранят снимок карточки справочника на момент выбора; изменение
справочника не меняет сохранённые сметы. Неизвестная ставка остаётся неизвестной и блокирует строку,
явный ноль — число 0. Доставка задаётся на партию и распределяется по брутто с остатком в последней
строке; добавлять ли долю доставки в таможенную стоимость — выбор строки. Сбор — один раз на
декларацию. Цена единицы — 4 знака, денежные значения — 2; округление до зависимых формул.

## Excel

Обычный XLSX до 50 МБ и 100 МБ после распаковки, до 5 000 строк на листе, 10 000 в книге и 100
колонок. Сотрудник выбирает лист, строку заголовков и назначает колонки. Макросы, внешние связи и
формулы без результата не исполняются. Числа: точка или запятая — дробная часть, тысячи — только
пробелом; «1,500.50» отклоняется. Встроенные JPG/PNG привязываются к строкам по якорю рисунка; URL
фото не скачиваются.

## Доступ сотрудников

Локальный вход по email и паролю, непрозрачные серверные сессии в PostgreSQL. Роль, владельца
сметы и административные поля нельзя передать из браузера. Email нормализуется (нижний регистр,
уникальный индекс `lower(email)`), пароль — bcrypt (длинные фразы — через SHA-256), минимум 8
символов. Доступ к сметам проверяется по владельцу на сервере. Лимит входа — в памяти процесса;
перед горизонтальным масштабированием нужен общий limiter.

## Справочник ТН ВЭД

`tnved_directory_entries` — операторский справочник, а не официальное хранилище: несколько
названий одного кода, синонимы, китайское название, ИТС компании, ставки с периодами и источниками,
статус проверки («Проверено» ставит только администратор). Архивирование не удаляет запись.

## Открытые вопросы

- Официальный источник кодов ТН ВЭД, описаний, примечаний и ставок, лицензия и частота обновления.
- Применение ставок перечня РК в расчёте; выбор производителя для индивидуальной ставки антидемпинга.
- Подтверждение email, восстановление пароля, 2FA, аудит действий.
- Утверждённое правило наименования для декларации (сейчас — по образцам «Наименование .xlsx»).
